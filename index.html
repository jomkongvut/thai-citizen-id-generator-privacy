ภาษาไทย English

ภาษาไทย

สรุป: ส่วนขยายนี้ไม่เก็บ ไม่ส่ง และไม่ขายข้อมูลส่วนบุคคลของคุณ ทุกอย่างทำงานในเครื่องของคุณ และส่วนขยายไม่เชื่อมต่ออินเทอร์เน็ตเลย

1. ข้อมูลที่เราเก็บ

เราไม่เก็บข้อมูลส่วนบุคคลใด ๆ ไม่มีบัญชีผู้ใช้ ไม่มีระบบวิเคราะห์ (analytics) ไม่มีโฆษณา และไม่มีการติดตามพฤติกรรม ส่วนขยายไม่ส่งคำขอเครือข่ายไปยังเซิร์ฟเวอร์ใด ทั้งของเราและของบุคคลที่สาม ฟอนต์และไอคอนทั้งหมดรวมอยู่ในตัวส่วนขยาย

2. ข้อมูลที่บันทึกไว้ในเครื่องของคุณ

เพื่อให้ใช้งานต่อเนื่องได้ ส่วนขยายบันทึกข้อมูลต่อไปนี้ไว้ใน chrome.storage บนเครื่องของคุณเท่านั้น ไม่มีการส่งออกไปที่ใด

  • ประวัติเลขบัตรที่สร้างล่าสุด และรายการโปรด (เป็นข้อมูลทดสอบที่สร้างขึ้น ไม่ใช่ของบุคคลจริง)
  • สถิติการใช้งาน เช่น จำนวนที่สร้าง จำนวนที่ตรวจสอบ และจังหวัดที่ใช้บ่อย
  • การตั้งค่า เช่น ภาษา ธีม และรูปแบบไฟล์ส่งออก

คุณลบข้อมูลเหล่านี้ได้ทุกเมื่อด้วยปุ่มล้างประวัติและรีเซ็ตสถิติในส่วนขยาย และข้อมูลทั้งหมดจะถูกลบเมื่อถอนการติดตั้งส่วนขยาย

3. การเติมฟอร์มและหน้าเว็บที่คุณเปิด

ส่วนขยายจะเข้าถึงหน้าเว็บก็ต่อเมื่อคุณสั่งเท่านั้น คือเมื่อกดปุ่ม "เติมลงฟอร์มในแท็บนี้" หรือเลือกเมนูคลิกขวา "แทรกเลขบัตรประชาชน (ข้อมูลทดสอบ)" และเข้าถึงเฉพาะแท็บที่คุณเปิดอยู่ในขณะนั้น ส่วนขยายไม่มีสิทธิ์อ่านเว็บไซต์ทั้งหมด

เมื่อเติมฟอร์ม ส่วนขยายอ่านคุณสมบัติของช่องกรอก (เช่น ชื่อช่อง ป้ายกำกับ และข้อความตัวอย่าง) เพื่อเลือกช่องที่เหมาะสม และจำค่าเดิมของช่องไว้ชั่วคราวในหน้านั้นเพื่อให้กดเลิกทำได้ ข้อมูลเหล่านี้ไม่ถูกบันทึกถาวรและไม่ถูกส่งออกไปที่ใด ส่วนขยายไม่อ่านเนื้อหาอื่นของหน้าเว็บ

4. สิทธิ์ที่ส่วนขยายขอ

storage บันทึกประวัติ รายการโปรด สถิติ และการตั้งค่าไว้ในเครื่องของคุณ
activeTab เข้าถึงแท็บที่คุณเปิดอยู่ เฉพาะตอนที่คุณสั่งเติมฟอร์มหรือแทรกเลขบัตร
scripting ใส่สคริปต์เติมฟอร์มลงในแท็บนั้นเมื่อคุณสั่ง แทนการทำงานบนทุกเว็บไซต์ตลอดเวลา
contextMenus เพิ่มเมนูคลิกขวา "แทรกเลขบัตรประชาชน (ข้อมูลทดสอบ)" ในช่องกรอกข้อความ
notifications แสดงการแจ้งเตือนต้อนรับหนึ่งครั้งเมื่อติดตั้งครั้งแรก

5. คลิปบอร์ด

ส่วนขยายเขียนลงคลิปบอร์ดเฉพาะเมื่อคุณกดคัดลอก หรือเปิดใช้ "คัดลอกอัตโนมัติ" ไว้ และไม่อ่านข้อมูลจากคลิปบอร์ดของคุณ

6. ข้อมูลที่สร้างขึ้น

เลขบัตรประชาชนและโปรไฟล์ที่สร้างขึ้นเป็นข้อมูลทดสอบที่ถูกต้องตามสูตรคำนวณเท่านั้น ไม่ได้มาจากฐานข้อมูลของบุคคลจริง ชื่อทุกชื่อสร้างจากคำที่แปลว่า "ทดสอบ" "ตัวอย่าง" หรือ "สมมติ" และอีเมลใช้โดเมน @example ที่ส่งถึงใครไม่ได้ ใช้สำหรับพัฒนาและทดสอบซอฟต์แวร์เท่านั้น

7. ลิงก์ภายนอก

ส่วนขยายมีลิงก์ไปยัง buymeacoffee.com ซึ่งจะเปิดในแท็บใหม่เมื่อคุณคลิกเท่านั้น เว็บไซต์ดังกล่าวมีนโยบายความเป็นส่วนตัวของตนเอง และส่วนขยายไม่ส่งข้อมูลใดไปพร้อมกับลิงก์

8. เด็ก

ส่วนขยายนี้ออกแบบสำหรับนักพัฒนาซอฟต์แวร์ และไม่เก็บข้อมูลของผู้ใช้ทุกวัย รวมถึงเด็ก

9. การเปลี่ยนแปลงนโยบาย

หากนโยบายนี้เปลี่ยนแปลง เราจะปรับปรุงหน้านี้และวันที่มีผลด้านบน ประวัติการแก้ไขทั้งหมดดูได้ใน GitHub repository

English

In short: this extension does not collect, transmit or sell any personal data. Everything runs on your device, and the extension makes no network requests at all.

1. Data we collect

None. There are no accounts, no analytics, no advertising and no tracking. The extension sends no network requests to any server, ours or a third party's. Fonts and icons are bundled inside the extension.

2. Data stored on your device

So that it can pick up where you left off, the extension keeps the following in chrome.storage on your own device only. None of it leaves your device.

  • Your recent generated IDs and favourites (generated test data, not real people's data)
  • Usage statistics such as how many IDs were generated or validated and the most-used provinces
  • Settings such as language, theme and export format

You can delete this at any time with the clear-history and reset-statistics buttons, and all of it is removed when you uninstall the extension.

3. Form filling and the pages you visit

The extension touches a web page only when you ask it to — by clicking "Fill the form in this tab" or choosing the right-click "Insert a Thai citizen ID" item — and only the tab you are on at that moment. It has no permission to read websites in general.

When filling a form, it reads the attributes of the form fields (such as their name, label and placeholder) to decide which value goes where, and briefly keeps the fields' previous values in that page so the fill can be undone. None of this is stored permanently or sent anywhere, and the extension does not read any other content of the page.

4. Permissions

storage Keep history, favourites, statistics and settings on your device.
activeTab Access the tab you are viewing, only when you ask to fill a form or insert an ID.
scripting Inject the form-filling script into that tab on request, instead of running on every website all the time.
contextMenus Add the right-click "Insert a Thai citizen ID" item for text fields.
notifications Show a single welcome notification on first install.

5. Clipboard

The extension writes to the clipboard only when you copy something or have "Copy to clipboard automatically" turned on. It never reads your clipboard.

6. Generated data

Generated citizen IDs and profiles are test data that is mathematically valid but taken from no real person. Every name is built from words meaning "test", "sample" or "fake", and email addresses use reserved @example domains that can never be delivered. It is intended for software development and testing only.

7. External links

The extension links to buymeacoffee.com, which opens in a new tab only when you click it. That site has its own privacy policy, and the extension sends no data along with the link.

8. Children

The extension is designed for software developers and collects no data from users of any age, including children.

9. Changes to this policy

If this policy changes, this page and the effective date above will be updated. The full history of changes is in the GitHub repository.

10. Contact

Questions about this policy can be raised as an issue at github.com/jomkongvut/thai-citizen-id-generator-privacy/issues.
