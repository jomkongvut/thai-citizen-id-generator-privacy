# Thai Citizen ID Generator — Privacy Policy

Privacy policy for the **Thai Citizen ID Generator** Chrome extension, in Thai and English.

**Read it here:** https://jomkongvut.github.io/thai-citizen-id-generator-privacy/

In short: the extension collects no personal data and makes no network requests. History, favourites, statistics and settings stay in `chrome.storage` on the user's own device.

The page is `index.html`, served by GitHub Pages. The commit history of this repository is the change log of the policy.
